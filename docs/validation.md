# 外部 CE 发布版验证

日期：2026-10-17。程序适配 Windows x64、.NET Framework 4.8、CE 7.5 x64、《活侠传》release_1.0.6000.2。

2026-10-18 发布整理包含 GPT 娘多尺寸图标、角色署名和 GitHub 下载说明。下列功能结果来自 2026-10-17 外部 CE 版测试；图标显示及 GitHub 上传须以本次独立检查结果为准，不由历史测试推定通过。

## 本次实际通过

- C# WPF x64 编译、CT XML 与 Lua 5.3 语法检查；启动表只有三条静态记录，不含已保存的运行时地址。
- 全新中文及空格目录首次启动，默认 CE 路径为空，显示设置引导；外部 CE 配置保存后启动独立隐藏后台并连接存档。
- 当前 BepInEx 6 / HarmonyX 2.10.2 环境：银两 43217 → 43218 → 43217；行动次数冻结时写入 2 被恢复为 3，解除后保持 2，再恢复 3。
- 银两不减反增开启后，实际对象 AddValue(-1) 产生 +1，随后恢复数值；关闭功能与停止全部修改成功，复用现有 Harmony。
- 普通窗口 15 号字：侧栏透明角色、资源页与设置页实际显示检查；README 采用实际窗口截图，没有放入参考三视图。
- 输入草稿保持与简繁体搜索自检通过。
- 原版环境：通过 Steam 为本次启动传递 `--doorstop-enabled false`，核对实际进程参数，并确认增强前的 BepInEx／Harmony 程序集清单为空；按需加载助手提供的 HarmonyX 2.10.2 后，资源改值恢复、行动冻结／解除及真实 AddValue(-1) 反转／撤销均通过。配置文件前后 SHA256 相同。
- 正常关闭测试窗口后，其自有 CE 与助手进程均退出；最终 exe 的后台冒烟测试通过启动、中文通信、无游戏时拒绝连接和退出清理。
- 最终 exe 的资源清单和哈希检查通过：仅提供增强依赖、自有引导程序集、许可与角色资源，没有 CE、Lua 运行库或 Mono 采集器。
- 中文及空格目录的缓存释放、缺失文件重新释放、损坏文件哈希修复通过；空路径、不存在路径、只复制单个 CE exe 的不完整安装均被拒绝。
- GitHub 目录的独立副本可直接编译，并通过 Lua／结构检查与发布检查，不依赖原工作区或本机 BepInEx 目录。

本次实际原版游戏进程参数已核对；首次直接启动曾被 Steam 重新拉起并丢失参数，该次不计为原版通过，以后续参数及程序集检查均通过的结果为准。

## 历史验证

前一版已经在原版游戏和本机 BepInEx 环境分别验证：依赖初始化、资源修改恢复、冻结解除、增强撤销、读档重新定位和游戏重启。原版通过单次 Doorstop 禁用参数启动并确认没有预载 BepInEx／Harmony。

这些是历史结果，不替代当前外部 CE 发行版的实测。现版本继续保留相同增强引导与 Unicode 原生加载修复。

## 尚未验证

- 战役、决斗、实际天命轮盘、完整炼丹／修炼升级流程和时间修改对剧情的影响。
- 其他游戏版本、CE 其他版本、其他 BepInEx 版本及所有 Windows DPI／多显示器组合。

测试不主动保存游戏；已经进行的测试数值均恢复。游戏自动保存仍由游戏自身控制。
