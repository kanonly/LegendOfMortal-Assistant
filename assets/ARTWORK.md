# 角色素材说明

`mascot.png` 是本项目使用的 GPT 助手拟人形象：白发、紫瞳、龙角、尖耳、白紫服饰的 Q 版半身挥手角色。

**GPT娘角色来源：ZipZipPipe**

- 参考设计由项目发起者提供；参考原图与三视图不随项目分发。
- 新图使用 OpenAI **imagegen 内置工具**生成，透明背景，无文字。生成日期：2026-10-17。
- 用途：侧栏小头像、设置页“关于本项目”、README，以及 exe 与窗口图标。
- 多尺寸 ICO 由现有 `mascot.png` 转换生成，包含 16、32、48、64、128、256 像素图层，保留透明背景；图标转换没有重新绘制角色。
- 本项目允许在遵守项目非商业许可及参考设计已有权利的前提下随项目使用和分享本素材；不对原始参考设计及其中第三方标识主张额外授权。
